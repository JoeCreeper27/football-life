# FootballLife ⚽ 足球人生模擬器

12 歲從國中球隊開始，選一個出身國家、選一種出身背景，
決定要進足球學校還是留在校隊，然後一路往上爬到五大聯賽，
最終目標是把自己的代表隊帶進世界盃。純文字生涯養成，種子化，每一個決定都算數。

> 玩法概念致敬 [yakyulife](https://github.com/LeoGGcat/yakyulife)（CC BY-NC 4.0），詳見 [NOTICE.md](NOTICE.md)。

---

## 快速開始

**不需要安裝任何東西就能玩**（純 ES modules）：

```bash
python3 -m http.server 8000
# 開 http://localhost:8000
```

要用 Vite 開發與建置成單一 HTML：

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 產出 dist/index.html（單檔，可直接丟 GitHub Pages）
npm run sim      # 跑 1000 局平衡模擬（隨機國家）

# 分享圖排版工作台（改 src/share.js 存檔即重繪，不必重跑生涯）
# → http://localhost:5173/share-preview.html

# 單一國家對表（國家碼見下方階梯表）
node tools/balance-sim.js 600 balanced TW
```

推上 `main` 後 GitHub Actions 會自動建置並部署到 Pages
（Settings → Pages → Source 選 **GitHub Actions**）。

## 架構

```
src/
├─ engine/            ★ 純函式，零 DOM 相依，可在 Node 裡跑
│  ├─ rng.js          種子化亂數（mulberry32）
│  ├─ data.js         所有平衡數值：能力、位置、國家、出身、聯賽階梯、球會、事件卡、特性
│  ├─ state.js        狀態建立、能力成長、綜合評價、陣中地位
│  ├─ sim.js          出場時間、賽季數據、傷病、薪資、衰退
│  └─ flow.js         年度流程狀態機
├─ main.js            UI：記錄流 + 選項按鈕 + 狀態列 + 能力雷達圖
├─ share.js           UI：生涯結算分享長圖（純 canvas，可用 share-preview.html 單獨預覽）
tools/balance-sim.js  蒙地卡羅平衡模擬
docs/SPEC.md          完整開發規格書
```

### 引擎介面只有兩個函式

```js
import { createState } from './src/engine/state.js';
import { run, answer } from './src/engine/flow.js';

const s = createState('abc123', {
  name: '王小明', number: 10, group: 'FW',
  nation: 'TW',      // TW JP KR US BR AR GB ES DE IT FR PT NL
  origin: 'local',   // local 純本地 / mixed 混血 / immigrant 移民
});
s.step = 'YEAR_START';

let r = run(s);                  // 推進到下一個決策點
r = answer(s, r.pending.options[0].v);   // 回答後繼續推進
// r = { cards: [...], pending: {...} | null, state }
```

`cards` 是純資料（`{tone, title, html}`），UI 層才決定怎麼畫。
因此同一份引擎可以：

- 在瀏覽器跑遊戲
- 在 Node 裡跑萬次模擬調平衡
- 之後移植 Kotlin 做 Android，或放在 server 上用 `{seed, actionLog}` 重放驗證排行榜成績（防作弊）

### 決定論

所有遊戲隨機都走 `Rng`，並記錄 `cursor`。因此：

- 同種子 ＋ 同選擇 ＝ 同一段人生，`?seed=xxx` 就是可分享的劇本
- 存檔只要存 `{seed, cursor, state}` 就能完整還原
- 純視覺效果請用 `Math.random()`，**不要**污染這條序列

⚠️ 任何新增／刪除 `rng` 呼叫的規則改動都會讓舊種子結果漂移。發版時請更新 CHANGELOG。

## 核心機制

| 系統 | 說明 |
|---|---|
| **陣中地位** | `squadGap = 綜合 − (聯賽基準 + 球會等級 + 位置競爭)` → 核心／主力／輪替／替補／看台席，決定出場率。**能力夠了也不一定有球踢**，這是與棒球版最大的差異 |
| **球會等級** | 豪門／爭冠／中游／保級，獨立於聯賽等級。豪門板凳 vs 中游主力是每季的真實抉擇 |
| **能力養成** | **FIFA 式 1–99 量表**、潛力天花板、階梯成本、蓄力槽（未滿一級不蒸發，扣值 1:1 立即生效） |
| **訓練課表** | 不直接點能力，而是選訓練項目。外場 12 項、門將 8 項（同名訓練對門將的意義不同：重量訓練練的是爭頂制空、衝刺訓練練的是門線爆發）。每項餵養多個能力，權重正規化所以一顆骰的總產出固定，差別在分給哪幾項 |
| **必修 vs 自由** | 足球學校有固定課表（體能＋戰術自動吃掉前兩顆骰），高中校隊全部自由分配。快，但課表不是你的 |
| **自主加練** | 排完課表可再多練一項，代價是當季受傷率 +6 與身體負荷；**不加練則這季多抽一張事件卡** —— 休息不是空手而歸 |
| **天賦係數** | 每個球員出生時抽一個 talent，把所有潛力一起往上或往下推。潛力上限刻意壓在 **50–90**（體能保底 60）—— 散得太開的話出生就決定一切（實測相關係數曾達 0.888，現為 0.61）|
| **軟上限** | 突破天賦上限的成本很低，但超出的部分每年會被拉回 10%。**推得上去、守不住**，而不是用天價成本擋在門口 |
| **韌帶量表** | 由 `(速度+對抗) × 踢法 × 出場負荷` 累積；爆表時二選一：動手術（報銷一年、速度回春）或打封閉硬撐（55%，失敗重大斷裂） |
| **非均勻衰退** | **25 歲就開始、每一項都會掉**，只是體能類（速度／體能／對抗）與技術類差一個量級（38 歲時 2.40 vs 0.75）。掉幅再乘上**體能修正 —— 體能越好衰退越慢**，而體能本身也在掉，這個正回饋就是老將斷崖式衰退的來源。唯一的年齡硬限制是速度過 30 歲只能練回上限、不能再突破 |
| **出身國家** | 15 個國家，各有不同的青訓水準、國內聯賽階梯、代表隊實力，以及有沒有大學足球這條退路。台灣國內天花板只有企業聯賽，巴西／西班牙一出生就在職業體系裡 —— 這是遊戲最主要的難度旋鈕 |
| **體型** | 開局隨機（高大／中等／矮小），不是玩家選的。高大的對抗頭球防守有先天優勢、速度盤帶吃虧，矮小相反；門將則是撲救制空 vs 短傳體能。優勢同時作用在初始值與潛力上限 |
| **出身背景** | 純本地（徵召門檻 −3）／**原住民**（體能類潛力上限 +3，僅台灣／日本／美國／巴西／阿根廷）／混血（最高潛力 +3，18 歲時可改代表另一國）／移民（起步吃虧、徵召門檻 +3，但體能類上限 +3 且旅外窗口寬）。非洲兩國只有純本地與混血，純本地自帶體能類上限 +3 |
| **養成分岔** | 國中三年後二選一：**足球學校**（訓練骰 +1、體能類效率 ×1.7、技術類 ×0.8）或**高中校隊**（技術類 ×1.5、體能類 ×0.95，保留升學與第二人生）。兩條路的綜合評價與生涯峰值幾乎相同，差別在風格 |
| **上場時間換成成長** | 上季出場率 ≥70% 多一顆訓練骰、<30% 少一顆，評分 ≥7.2 再多一顆。坐板凳的人練不起來 |
| **轉會窗** | 升級／同級轉戰其他地區／降級／外租／返回家鄉，每個選項都標明地區。升級目的地刻意跨洲分散，所以「要去哪個地區」本身就是一個決策 |
| **成長四階段** | 潛力期（≤18，3 顆骰 3–11）→ 成長期（3 顆 2–8）→ 巔峰期（3 顆 1–7，成本 ×2）→ 維持期（2 顆 1–6，成本 ×2.6）。點數重壓在 24 歲前，身分在 18 歲之前就成形；後段仍練得動，只是貴 |
| **連帶成長** | 環狀圖，每個能力剛好帶動另外兩個（體能→速度、對抗；防守→對抗、體能；傳球→視野、射門……）。門將能力組不同，走獨立的一張表。帶動的點數走蓄力槽，且只能帶到天賦上限，要突破天賦仍得專門訓練 |
| **原型** | 15 種原型不是開局選的，是前幾年加點長出來的。18 歲時依能力分布給 2–3 個選項，選定後主修成本 ×0.7、主修潛力 +4 —— 成長方向被收窄，這才是原型的重量。走到極致會進化，31 歲跑不動時會有位置會議 |
| **球迷聲望** | 0–100，影響主場表現、薪資、分紅與引退評價。≥90 且同隊 ≥8 年會球衣退休，≤20 則被掛牌求售。負面事件扣得比正面加得兇 |
| **位置轉型** | 21 歲後若改踢別的位置綜合會高 3 分以上，季末開「位置會議」。**這是賭注不是升級**：成功率隨年齡遞減（21–25 歲 80%、30 歲 55%、35 歲 30%），失敗會白費半個賽季且位置回不去 |
| **命運與機會** | 低頻高影響卡：傳奇球星指導（24 位，需人在對應地區或屬於該國）、伴侶背叛、假球指控、一夕爆紅……影響幅度是一般事件的數倍。**傳奇指導會抬高天賦上限本身**，這是它與一般訓練的本質差異，也是低天賦球員唯一的樂透 |
| **商業與形象** | 球鞋合約、電玩封面、自傳、紀錄片、家鄉球場命名……多數綁定球迷聲望與聯賽層級，有實際收入結算。事件卡共 142 張，80 張有情境專屬的選項文案 |
| **退役分岔** | 30 歲後除了高掛球鞋，還可以賭一把轉任教練。資格看閱讀比賽的能力、隊長經歷或學歷；成功則執教 6–14 年、大幅增加收入與聲望，失敗則兩季下台 |
| **兵役** | 台灣與韓國限定，20–24 歲強制觸發：體育替代役／入伍（少一季）／海外役男延期 |
| **結算分享圖** | 生涯結束後一鍵把整段人生畫成直式長圖並自動複製到剪貼簿。**雷達圖畫的是生涯巔峰而不是引退當下**（平均差 8.5 分 ovr），圓心標巔峰綜合。純 canvas 手繪（單檔 build 抓不到 CDN），配色跟著結局地區走，種子碼印在圖上，看到圖的人才踢得到同一段人生 |
| **世界盃** | 代表隊整體實力由國家決定，個人能力最多再加 +8。弱國晉級是全遊戲最大的情緒高點，強國則是擠進名單本身就很難 |

## 生涯階梯

聯賽分成 7 個層級，同一層有多個地區的聯賽；你的出身國家決定「哪些算國內、
從哪一層開始、國內能爬到哪」。要往上就得旅外，而旅外有年齡窗口。

| 層級 | 亞洲 | 歐洲 | 南美 | 北美 |
|---|---|---|---|---|
| 7 五大聯賽 | — | 英格蘭／西班牙／德國／義大利／法國 | — | — |
| 6 五大次級 | — | 英式次級／歐陸次級 | — | — |
| 5 歐洲跳板 | — | 葡超／荷甲／跳板聯賽 | — | — |
| 4 洲際頂級 | J1／K1 | — | 巴甲／阿甲 | MLS |
| 3 次級職業 | J2／K2 | 歐洲第三級 | 巴乙 | 美職次級 |
| 2 低階職業 | J3／K3 | 歐洲第四級 | 巴丙／阿乙 | 美國三級 |
| 1 半職業 | 台灣企業聯賽／JFL／K4 | 歐洲第五級 | 南美地區聯賽 | 美國業餘 |

台灣的國內天花板就是第 1 層 —— 想再往上，**只能出國**。這是台灣 run 的核心設定。

## 目前的平衡狀況

`npm run sim` 的實測結果（3000 局，balanced 策略，隨機國家）：

| 指標 | 目前 | 目標 | |
|---|---|---|---|
| 登上五大聯賽 | 18.4% | 15–20% | OK |
| 登上洲際頂級以上 | 61.6% | 55–65% | OK |
| 25 歲前退出 | 10.4% | 8–14% | OK |
| 生涯至少一次重傷 | 63.0% | 40–65% | OK |
| 一輩子沒旅外 | 16.6% | 25–50% | 偏低（模擬機器人有得升就升，見下）|

能力分布（專注型玩法，500 局）：

| | 平均 | P90 | P95 | 最高 |
|---|---|---|---|---|
| 18 歲 ovr | 63.0 | 69 | — | — |
| 峰值 ovr | 77.1 | 84 | 86 | 92 |

巔峰年齡平均 **26.3 歲**。天賦與峰值的相關係數 **0.61**
（曾經是 0.888 —— 那時候等於出生就決定一切）：

| 出生天賦 ovr | 峰值 | 上五大 |
|---|---|---|
| 0–65 | 70.0 | 0.8% |
| 65–75 | 76.4 | 6.1% |
| 75+ | 80.7 | 22.3% |

各國登上五大聯賽的比例（同一份模擬）：

```
台灣 6%  日本 8%  韓國 7%  美國 4%  巴西 11%  阿根廷 15%  英國 12%
西班牙 17%  德國 19%  義大利 12%  法國 18%  葡萄牙 18%  荷蘭 11%
奈及利亞 16%  象牙海岸 17%
```

每次改完跑 `npm run sim 2000`，並用 `node tools/balance-sim.js 600 balanced TW`
之類的單國模式對表。

> 註：模擬機器人「有得升就升」，所以「一輩子沒旅外」在模擬裡永遠接近 0%，
> 這個指標要看真人玩家的行為，不適合拿模擬值對表。
